    Neuer Kurztext

    Erstellt einen Kurztext in einem bestehenden Thema, optional mit Datei-Anhang.

    Wird als Ordnername verwendet.
    Erscheint in der Download-Liste und im WordPress-Snippet. Leer lassen, um den Titel aus \chapter{…} zu übernehmen.
    Optional. Die Datei wird vor dem Speichern probehalber kompiliert; bei LaTeX-Fehlern wird nichts angelegt und die Fehlermeldung angezeigt.

    Bilder hochladen

    Lädt Bilder/Grafiken (PNG, JPG, GIF, EPS, PDF, SVG) in den gemeinsamen Ordner upload_dir/attachment/Bilder, der von allen Kurztexten referenziert werden kann.

    Mehrfachauswahl möglich. Dateien mit gleichem Namen werden überschrieben.

    Themen verwalten

    Umbenennen oder löschen. Beim Löschen werden alle zugehörigen Kurztexte mitgelöscht.

        WordPress-Snippet

        Auswahlliste für die WordPress-Seite. Enthalten sind nur Texte mit hochgeladener .tex-Datei. In WordPress in einen Block „Individuelles HTML“ einfügen, damit keine <p>/<br /> eingefügt werden.

        Dynamisch (empfohlen)

        Lädt die Liste beim Aufruf der WordPress-Seite live von diesem Server. Muss nur einmal eingefügt werden; die mitgelieferte Liste dient nur als Rückfall, falls der Server nicht erreichbar ist.
